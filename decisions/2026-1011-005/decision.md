# 無設定檔的外接磁碟探索與 run 紀錄

日期：2026-10-11（Asia/Taipei；依對話回填）。

## 決策

預設不使用設定檔，自動對目前已掛載的外接磁碟資料 volumes 執行卸載、睡眠及恢復。每次循環保留可查詢的 run 流水帳，並提供基本的列出、查看、補救、明確結案及清理操作。T500 白名單與特殊警告延後實作。

## 對話依據

使用者要求「不需要任何 config，預設行為是外接 disk 在 sleep 前 unmount，sleep wakeup 後按照清單 mount」，並要求「對於暫存記錄方式與位置（這次，流水帳）有明確的定義，以及設計基本的維護操作指令」。稍後再明確指示「先略過 白名單 的處理」、「先以不需要 configuration 的角度來修正」、「按照你的設計開始變更」，並要求 requirements 與 implementations 對應。

## 背景與影響

此決策取代[採用 `.env` 設定檔](../2026-1011-003/decision.md)。既有 `.env` 保留但不讀取，`--config` 停用。具體行為與驗收以[需求規格](../../docs/requirements.md)和[實作對照](../../docs/implementation.md)為準；白名單不屬於此次交付。
